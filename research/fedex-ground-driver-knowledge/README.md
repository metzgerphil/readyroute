# Ready Route Answers v2 workbench

This is the clean authoring workspace for the replacement corpus. It contains no facts or records from the archived v1 dataset.

Place original source material in `sources/`, which remains excluded from Git because it may contain restricted material. Register every accepted source in `inventory/source_inventory.csv`. Author evidence-backed records in `knowledge/records.jsonl`, then add evaluation cases under `validation/`.

Do not copy records, evidence summaries, aliases, or answer text from the v1 archive. If historical material is later supplied again as an authorized source, treat it as a new intake item and review it from the original bytes.
