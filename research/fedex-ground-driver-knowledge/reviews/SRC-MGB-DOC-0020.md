# SRC-MGB-DOC-0020 — Assigning Same Pickup ID to Multiple Pickups in FORGE

- Review date: 2026-08-10

- Coverage: 3/3 pages from archived original PDF

The guide documents assigning an existing pickup ID to multiple unmanifested pickups. It includes separate sequences depending on whether the original pickup stop remains open or has already been closed.

The source is version-sensitive. Because it predates the current FORGE 3.3 guide and the current guide has not yet been fully reviewed for this feature, this workflow is retained as review evidence rather than a definitive production instruction.
