# SRC-MGB-PAGE-0025 — Meeting customer expectations when delivering to lockers

- Review date: 2026-08-09
- Published: 2024-05-09
- Coverage: complete visible authenticated article
- Status: fully reviewed
- Durable capture: `captures/mygroundbiz/locker_delivery_ppod_2024-05-09.txt`

The article establishes that locker delivery is limited to residential packages designated for release without a signature. Residential Delivery Signature Option packages and commercial packages for residential-complex employees are not eligible. If a package will not fit or the locker malfunctions, personnel should contact an employee of the residential location for an agreed alternate release location and should not place the package beside the locker without that agreement.

For a locker PPOD image, the article requires a clear view of the package placement, the used compartment, and adjacent compartments while excluding locker numbers, people, addresses, labels, and other personally identifying information. The image must not show the package delivered outside the locker.

The newer OP-117 remains the controlling source for code 007 and return when no alternate location is approved, wrong-compartment recovery, access-code handling, oversize/hazmat restrictions, and one-stop-per-customer-address logic. The article corroborates and extends the locker eligibility and PPOD branches; it does not replace those newer procedures.
