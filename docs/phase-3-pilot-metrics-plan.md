# Phase 3 pilot metrics plan

## Core measures

- Active drivers and participating companies.
- Questions and questions per active driver.
- Correct canonical top-1 match from human-reviewed samples.
- Clarification rate and clarification accuracy.
- Production-eligibility accuracy.
- Procedure-fidelity and unsupported-instruction rate.
- No-answer rate and repeated unresolved situations.
- Helpful/not-helpful rate and negative reason.
- Reported incorrect/questionable answers by failure category and severity.
- Median, p90, p95, and p99 end-to-end latency; transcription, API, retrieval/database, and rendering components where measurable.
- Authentication, device replacement, system error, timeout, and duplicate-submit counts.
- Common operational categories and knowledge gaps.

## Manager evidence

Ask managers whether routine questions changed, where confusion repeats, whether drivers consult Ready Route before calling, which guidance appeared questionable, and which usability problems blocked adoption. Treat this as qualitative pilot evidence, not proof of reduced mistakes or workload.

## Review rules

- Review 100% of negative feedback, escalations, and reported questionable answers.
- Review a randomized positive-answer sample sized to the named review capacity.
- Separate retrieval, classification, clarification, decision, generation, status, speech, and UX failures.
- Do not report answer quality using helpfulness alone.
- Do not claim operational or workload impact until controlled pilot evidence supports it.
