# Ready Route: which code applies when access is blocked?

Ready Route currently has three saved, owner-approved instructions. We need the precise boundary between them before activating the gate-code answer. This is a request to confirm the operating rule, not a new instruction for drivers.

## What the saved answers say

- **Code 007 — failed residential gate code.** The address is correct, but the customer's gate code does not work. Check FORGE and the label for a working code or note; call the customer if a number is available. If access still cannot be obtained, the saved answer says Code 007, cross the package with the work-area number/date/code, remove the Vision Label (SID sticker), and return it to the station. Approved August 27; label terminology updated August 28.
- **Code 001 — security prevents delivery.** Customer security measures or a closed road prevent delivery. The saved answer says Code 001 with a note explaining the actual reason, package crossing, SID removal, and station return. A security screening or escort delay that still allows delivery does not by itself justify Code 001. Approved August 19.
- **Code 001 — genuinely unsafe access.** The delivery point cannot be reached safely because of an unsafe road, bridge, access path, obstruction, clearance, animal, or turnaround condition. The saved answer says do not enter the unsafe condition; use Code 001 with a comment explaining the specific reason. Approved September 3.

## Why the app needs clarification

A locked security gate can fit the ordinary wording of both the first and second answers. "I cannot get through the gate" does not tell the app whether the code failed, a guard refused entry, access is unsafe, or entry is only delayed. Those are different facts, and the saved approvals do not explicitly state which rule takes precedence when they overlap.

We are not asking whether Code 007 or Code 001 is universally correct. We need the exact rule that separates the situations.

## Please confirm these cases

1. **Failed credentials only:** Correct residential address, gate code fails, no separate safety hazard, FORGE/label checked and the customer cannot be reached or cannot provide access. Is Code 007 correct, or Code 001? What fact makes that code correct?
2. **Security refuses access:** Correct address, but a guard or property-security policy refuses entry. Does Code 001 apply? Does residential versus business delivery change the answer?
3. **Two conditions together:** The gate code fails and the only alternative route is genuinely unsafe, such as a flooded road. Which condition determines the code?
4. **Temporary delay:** The guard will admit or escort the driver after a wait. Confirm whether neither code applies solely because of that delay, and whether there is any separate limit or condition we must record.

For each case, please supply the code, the fact that controls the choice, any required customer/BC contact, scanner comment, package marking/label treatment, station-return steps, and exceptions. If a decision depends on something the driver has not stated, give us the single clarification question the app should ask. Please do not assume an extra step: identify it explicitly if it is required.

We will preserve your exact explanation and approval scope, update the affected records, and test different driver phrasings against the same rule. The gate-code answer remains on hold until this is resolved.
