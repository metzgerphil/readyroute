# Source layer

`registry.jsonl` is generated from the complete research source inventory. Source IDs are persistent and must not be renumbered merely to match a cosmetic naming example.

Source records preserve identity, original location, dates/version, access and review status, supersession, local archive reference, interpretation limits, and review notes. Operational records cite exact source IDs and locators. A title or cross-reference to an unavailable document is not evidence for that document's contents.

Never overwrite an acquired source version. Preserve the prior bytes or authorized capture, checksum, locators, and supersession relationship.
