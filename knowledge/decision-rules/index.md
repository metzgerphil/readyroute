# Decision logic

The maintained decision map is [`research/fedex-ground-driver-knowledge/knowledge/decision_logic.md`](../../research/fedex-ground-driver-knowledge/knowledge/decision_logic.md). Canonical records store clarification requirements, conditions, exceptions, and related record IDs in machine-readable form.

Retrieval must determine whether a material variable is known before selecting a procedure. Common variables discovered in the corpus include service/signature type, delivery versus pickup, release eligibility, recipient/location type, package condition, prior-attempt state, scanner/FORGE state, form/revision identity, special service, and safety/access conditions. This list is descriptive, not a closed taxonomy.

Ask only the smallest clarification needed to select a safe branch. A verified general rule must not be substituted for a gated specialty branch.
